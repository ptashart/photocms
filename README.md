# PhotoCMS

PhotoCMS — бесплатная CMS для сайта-портфолио фотографа. Работает на PHP и SQLite, не требует Composer, MySQL или внешних сервисов для изображений.

[Демо](http://www.phcms.gt.tc/) · [Сайт автора](https://www.ptash.art) · [Инструкция](Инструкция%20по%20CMS.md)

## Возможности

### Портфолио и страницы

- Альбомы с галереями, лайтбоксом и блоком «Другие работы».
- Страницы из секций: текст, фото, галерея, кнопки, список работ, тарифы, FAQ, видео, форма связи.
- Блог с рубриками, тегами и редактором секций.
- Две темы, мобильное меню и адаптивная вёрстка.
- Предпросмотр несохранённых правок и браузерные черновики.

### Медиа и изображения

- Медиатека с загрузкой, alt, фокусной точкой и проверкой использования файлов.
- Адаптивные `srcset`, WebP и AVIF, атомарная генерация вариантов.
- JPEG/PNG/WebP сохраняют настройки автора, копирайта, кредита и лицензии в XMP/IPTC.
- Предварительная генерация OG-кадров и favicon.
- Оригиналы остаются закрытыми от публичного доступа.

### Заявки

- Заявки сохраняются в админке даже при сбое почты или Telegram.
- Восстановление введённых полей после ошибки.
- Сохранение UTM, `yclid`, `gclid`, первой страницы и источника перехода.
- Ограничение отправок, honeypot и защита токеном формы.

### SEO

- Canonical, Open Graph, JSON-LD, sitemap.xml и RSS.
- Автоматические 301-редиректы при смене адресов.
- Clean-param для рекламных меток без удаления аналитики.
- Поддержка Яндекс.Метрики, Google Analytics и Вебвизора через CSP.
- Настройки организации, услуг, цен и социальных ссылок.

### Безопасность и производительность

- Подготовленные SQL-запросы, CSRF, стойкое хеширование паролей и ограничение входа.
- Блокирующий CSP с nonce и `strict-dynamic`.
- Поддержка доверенных IPv4/IPv6 CIDR для прокси.
- HSTS на HTTPS и возможность вынести базу и сессии за пределы публичной папки.
- Кэш страниц и XML, безопасные SQLite snapshots и автоматические копии базы.
- Раздел «Сервер»: CPU, память, диск, версии компонентов, лимиты и предупреждения об обновлениях.

## Требования

- PHP 8.0 или новее.
- PDO SQLite, mbstring и DOM.
- GD или Imagick.
- Apache с mod_rewrite; пример для nginx приведён в инструкции.

## Установка

1. Загрузите содержимое пакета в корень домена.
2. Откройте сайт в браузере и создайте администратора в установщике.
3. Удалите или переименуйте `install.php`.
4. Заполните название, адрес сайта, контакты, SEO и права фотографа в настройках.

Подробное руководство: [Инструкция по CMS.md](Инструкция%20по%20CMS.md).

## Проверка кода

```sh
find . -type f -name '*.php' -print0 | xargs -0 -n1 php -l
php tests/smoke.php
```

GitHub Actions выполняет эти проверки для PHP 8.0, 8.3 и 8.4.
